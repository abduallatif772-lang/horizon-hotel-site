موقع فندق أفق صنعاء — دليل المبتدئ
====================================

ما الذي ستحصل عليه؟
- موقع عربي متجاوب مع الجوال والكمبيوتر.
- صفحة رئيسية، غرف وأجنحة، خدمات، معرض صور، ووسائل تواصل.
- نموذج طلب حجز يجهّز رسالة تلقائياً في واتساب.
- روابط اتصال وبريد إلكتروني.
- لا يحتاج إلى قاعدة بيانات أو اشتراك مدفوع لتجربته أو نشره كموقع ثابت.

مهم قبل النشر
-------------
هذا نموذج تجريبي باسم "فندق أفق صنعاء". البيانات والصور والأسعار والخدمات ليست بيانات فندق حقيقي، ويجب تحديثها قبل نشر الموقع رسمياً.
نموذج الحجز يرسل طلباً عبر واتساب فقط؛ لا يؤكد الحجز تلقائياً ولا يدير الغرف المتاحة أو الدفع. لا توجد بوابة دفع أو لوحة إدارة في هذه النسخة.

الخطوة 1: فتح الموقع على جهازك
------------------------------
1. فك ضغط الملف ZIP.
2. افتح المجلد riyadh_hotel_website.
3. اضغط على index.html لفتحه في المتصفح.
4. جرّب القائمة ونموذج الحجز. قد تحتاج إلى اتصال بالإنترنت لتحميل الخط والصور.

الخطوة 2: تعديل رقم واتساب
--------------------------
1. افتح ملف script.js ببرنامج المفكرة (Notepad) أو محرر نصوص.
2. في أول الملف ستجد:
   const HOTEL_WHATSAPP = "967772459459";
3. استبدل الرقم برقم الفندق مع رمز الدولة، دون علامة + أو مسافات.
   مثال توضيحي: 9677XXXXXXX
4. احفظ الملف.

الخطوة 3: تعديل رقم الاتصال والبريد
----------------------------------
افتح index.html وابحث عن:
- +967 772 459 459
- https://wa.me/967772459459
- abduallatif772@gmail.com
واستبدلها بالبيانات الصحيحة. إذا غيرت رقم واتساب في index.html، غيّره أيضاً في script.js.

الخطوة 4: تغيير الاسم والمعلومات
-------------------------------
في index.html ابحث عن "أفق صنعاء" و"HORIZON HOTEL" واكتب اسم الفندق الحقيقي.
راجع أسماء الغرف والخدمات والنصوص. احذف أي خدمة غير متوفرة فعلياً، وأضف العنوان وساعات العمل والأسعار الحقيقية عند اعتمادها.

الخطوة 5: نشر مجاني باستخدام GitHub Pages
-----------------------------------------
ستحتاج حساب GitHub مجاني:
1. أنشئ حساباً في https://github.com إذا لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً (New repository)، واجعله Public، وسمّه مثلاً horizon-hotel.
3. ارفع الملفات الثلاثة: index.html وstyle.css وscript.js. يمكنك أيضاً رفع README_AR.txt.
4. من صفحة المستودع افتح Settings ثم Pages.
5. تحت Build and deployment اختر Deploy from a branch.
6. اختر الفرع main والمجلد /(root)، ثم Save.
7. انتظر حتى يظهر رابط الموقع في صفحة Pages. قد يستغرق النشر عدة دقائق.

ملاحظات مهمة:
- الاستضافة الثابتة عبر GitHub Pages مجانية، لكن اسم النطاق الخاص مثل example.com عادةً يحتاج شراءً منفصلاً.
- الصور والخطوط الحالية مستضافة لدى خدمات خارجية، لذلك يلزم الإنترنت وقد تتغير روابطها. استخدم صوراً تملك حق استخدامها.
- لا ترفع كلمات مرور أو بيانات عملاء أو معلومات سرية إلى المستودع.
- GitHub Pages لا يشغّل خادماً أو قاعدة بيانات ولا يعالج الدفع. للحجوزات الحقيقية المؤكدة، ستحتاج لاحقاً إلى نظام حجز أو خدمة خلفية موثوقة؛ يمكننا بناء ذلك خطوة بخطوة حسب الميزانية.
